# CodeAlpha Data Science Internship Projects

Welcome to my GitHub repository!

This repository brings together three projects I completed as part of my **CodeAlpha Data Science Internship**. Through these projects, I had the opportunity to practise Python, explore real datasets and develop my understanding of data analysis and machine learning.

## My Projects

### 1. Car Price Prediction
In this project, I explored car-related data and built machine learning models to predict the selling price of used cars. I also compared different models to understand how accurately they could make predictions.

### 2. Sales Prediction Using Python
For this project, I analysed advertising data to understand how different advertising platforms influence product sales. I used machine learning models to predict sales and explored which advertising channels had the greatest impact.

### 3. Unemployment Analysis with Python
In this project, I explored unemployment data to understand employment trends and changes over time. I used Python libraries to analyse and visualise the data, making the results easier to understand.

## Tools and Technologies

Throughout these projects, I worked with:

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## What I Learned

Working on these projects helped me improve my practical skills in data cleaning, data visualisation, exploratory data analysis and machine learning. I also gained experience in training models, evaluating their performance and interpreting results.

Each project gave me an opportunity to apply what I had learned and build more confidence in working with data.
